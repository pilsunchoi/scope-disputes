# 조사범위 문언 코딩 코드북 (초벌, 2026-09-27)

코딩 단위는 조치(measure) 하나다. 조치의 마지막 유효판 문언을 코딩하고, 첫 판과 문언이 다르면 그 차이를 비고에 적는다.

## 1. 무엇을 코딩하나

두 부분을 따로 코딩한다.

- 부과대상 조건(scope_positive): 물품명과 기본 HSK 열거 말고, 부과대상을 좁히는 조건. 예: "두께가 6밀리미터 이상인 것", "코팅되지 않은 물품".
  - 모든 부령이 HSK를 열거하므로 기본 열거만으로는 "분류"로 코딩하지 않는다.
  - HSK로 범위를 다시 좁히거나 나눌 때만 "분류"로 코딩한다.
- 제외 요건(exclusion): "제외한다"로 부과대상에서 빼는 물품. 본문 단서와 제외 물품 별표를 모두 본다.

## 2. 유형

| 유형 | 정의 | 예 |
|---|---|---|
| 규격 | 측정 가능한 수치 조건. 치수, 중량, 함량, 순도, 점도, 물성 수치 | 두께 6mm 이상, 탄소 함유량 0.5% 이하, RTI 105도 이상 |
| 가공상태 | 수치가 아닌 물리적 형상·가공·표면·구조·색 | 측면 요철 가공, 금속 증착, 코팅 여부, 중공(구멍) 여부, 유채색, 수용액 상태 |
| 용도 | 사용 목적이나 최종 용도 | 모터 절연용, 염전용, ○○에 사용되는 것 |
| 분류 | HSK·HS 번호로 조건을 걸거나 제외 | 제4412호에 분류되는 것은 제외 |
| 제품지정 | 특정 모델명, 상표, 생산자·공급자의 제품을 이름으로 지정 | "구라레이의 PVA-117H", 공급자별 모델 목록 |

"제품지정"은 계획서의 다섯 유형에 없던 것이며 초벌 코딩에서 잠정으로 더했다.

한 조건이 여러 유형에 걸치면 모두 적는다. 예를 들어 "모터 절연용으로 두께 125㎛ 이상인 흰색 필름"은 용도, 규격, 가공상태다.

요약 유형(*_summary)은 다음 규칙으로 정한다.

- 해당 유형이 없으면 "없음"
- 하나면 그 유형
- 둘 이상이면 "복합"

## 3. 산출 열

| 열 | 값 |
|---|---|
| measure_id | 입력 그대로 |
| scope_positive_types | 부과대상 조건의 유형들. 세미콜론으로 구분. 없으면 빈칸 |
| scope_positive_summary | 없음/규격/가공상태/용도/분류/제품지정/복합 |
| exclusion_present | Y/N |
| exclusion_location | 본문/별표/둘다/없음 |
| exclusion_types | 제외 요건의 유형들. 세미콜론으로 구분 |
| exclusion_summary | 없음/규격/가공상태/용도/분류/제품지정/복합 |
| n_exclusion_items | 제외 항목 수(번호 붙은 항목이나 별개 물품 단위, 모델 목록은 공급자 단위로 1개씩). 없으면 0 |
| use_based | 부과대상 조건이나 제외 요건 어디든 용도 조건이 있으면 Y |
| changed_across_versions | 첫 판과 문언이 다르면 Y, 같으면 N |
| evidence_positive | 부과대상 조건의 근거 문구(짧게 인용) |
| evidence_exclusion | 제외 요건의 근거 문구(짧게 인용) |
| confidence | 높음/중간/낮음 |
| note | 판단이 애매한 이유, 판 사이 변화, 기타 |

## 4. 초벌 코딩에서 정한 판단 규칙

초벌 코딩 중에 코더들이 같은 방향으로 판단한 것을 규칙으로 옮겼다. 두 번째 코더도 이 규칙을 따른다.

- 공급자를 빼는 별표(예: 제3조제2항에 따른 부과대상 제외 공급자)는 물품의 범위가 아니므로 제외 요건으로 코딩하지 않는다.
- 가격약속 대상 공급자 별표도 제외 요건이 아니다.
- 본문이 "별표에 규정된 물품은 제외한다"처럼 별표를 가리키기만 하면 위치는 "별표"다. 본문 단서에 별개 조건이 따로 적혀 있으면 "둘다"다.
- 표준 규격 등급(JIS, ASTM, ASME, EN, NORSOK 등)은 규격이다. 특정 회사가 붙인 기호·등급·모델명(NAS 기호, 회사 고유 강종, 상품 모델명)은 제품지정이다.
- 형상(원형, 각형, 사각 형태), 재질 종류(침엽수, 니켈합금강 같은 재질 부류), 가공·표면 상태는 가공상태다.
- 목록이 "…등"으로 끝나 열려 있으면 이름이 적힌 항목만 센다. 비고에 열린 목록임을 적는다.
- 판 사이에 HSK 번호만 바뀌었으면 changed_across_versions는 Y로 두고 비고에 "HSK만 변경"이라 적는다.
- changed_across_versions는 부과대상 조건이나 제외 요건의 내용이 바뀐 경우에만 Y다. 공백, 소관 부처명, 개정 표시(<개정 …>), 공급자 별표만 바뀐 경우는 N이다. HSK 번호만 바뀐 경우는 앞 규칙대로 Y로 두고 비고에 적는다.
- 제외 항목 수(n_exclusion_items)는 별표의 번호 붙은 항목 단위로 센다. 한 항목 안의 가·나목이 서로 다른 물품이면 따로 센다. 공급자별 모델 목록은 공급자 하나를 한 항목으로 센다. 본문 단서의 별개 조건은 별표 항목에 더한다.

## 5. 미결 물음에 대해 정한 것 (2026-09-27)

일관성 점검에서 코드북이 답하지 못했던 물음 여섯을 다음과 같이 정했다. 원칙은 하나다. 이 코딩은 연구 질문 1(어떤 형식의 문언이 분쟁을 부르는가)에 답하려는 것이므로, 세관이 실제로 물품을 가를 때 쓰는 기준을 코딩한다.

1. 정의된 범주 아래 예시로 붙은 모델 목록("…등으로 정의에 해당하는 것")은 범주 하나로 센다. 목록이 "등"으로 열려 있으면 모델명은 예시일 뿐이므로 제품지정으로 코딩하지 않는다. 목록이 닫혀 있을 때만 제품지정이다.
2. 세율표나 부과대상 별표 안에 괄호로 적힌 "제외"는 제외 요건이며 위치는 별표다.
3. 이름을 누가 붙였는가로 규격과 제품지정을 가른다. 표준기구(JIS, ASTM, ASME, EN, ISO, IEC 등)가 붙인 등급·기호는 규격이고, 특정 기업(생산자든 구매자든)이 붙인 기호·부품번호·모델명은 제품지정이다. 표준 등급에 회사 접미사가 붙어 그 접미사가 물품을 가르면 제품지정이다.
4. changed_across_versions는 범위의 내용이 바뀐 경우에만 Y다. 제외 항목 안에서 회사명이나 강종명의 표기만 바뀐 경우는 N이다. HSK 번호만 바뀐 경우는 연구 질문 4 때문에 Y로 두고 비고에 적는다(4절 규칙 유지).
5. 같은 물품의 치수 구간만 다른 가·나목은 한 항목으로 센다. 형상이나 물품이 다른 가·나목(육각강과 원형강 등)은 따로 센다.
6. 3번의 기준을 표준 명칭에도 쓴다. IEC 전지 기호와 유리섬유 사 번수(G75 등)는 규격이고, 생산자 고유 모델 기호(DL123 등)는 제품지정이다. 이름만 있는 재질 부류(E-glass, 니켈합금강 등)는 가공상태이고, 함량 수치로 정의된 재질 조건은 규격이다.

초벌 코딩(`coder-a.csv`)에서 이 결정으로 바뀐 칸은 셋이다. M042와 M054의 exclusion_types에서 제품지정을 뺐고(요약은 복합 그대로), M062의 changed_across_versions를 N으로 바꿨다. 변경 내역은 `draft-v2/changes.csv` 끝에 있다.
