# 분쟁 결정문 항목 추출 지침 (초벌, 2026-09-27)

2단계에서 결정문마다 뽑는 항목과 그 값의 규칙이다. 계획서 7.2절의 항목을 따른다.

추출 단위는 결정 하나(data/disputes.csv의 한 행)다. 원문은 text_file에 있다. 조세심판원 결정에 처분청 사건번호로 실린 사본이 있으면 clip_text_files에도 있으나, 같은 결정이므로 text_file을 기준으로 읽는다.

## 1. 결정 단위 항목 (disputes 파일)

| 열 | 값 |
|---|---|
| dispute_id | 입력 그대로 |
| relevance | 덤핑방지관세의 적용(부과대상 여부, 세율, 공급자, 가격약속, 불복 적격 등)이 쟁점이면 "쟁점"이다. 덤핑방지관세가 사실관계나 인용에만 나오고 다투는 대상이 아니면 "언급". 전혀 관련이 없으면 "무관" |
| issue_group | 조사범위 / 조사범위 부수 / 공급자·세율 / 가격약속·과세가격 / 불복 적격 / 기타 / 무관. 정의는 아래 2절 |
| cited_decree_titles | 결정문이 인용한 덤핑방지관세 부과 규칙의 제명. 부령 번호와 날짜가 있으면 함께 적고, 여럿이면 " ; "로 잇는다. 예: 중국산 합판에 대한 덤핑방지관세 부과에 관한 규칙(기획재정부령 제813호, 2020.11.6.) |
| disputed_goods | 쟁점물품의 서술(물품명, 규격, 형태). 100자 안팎 |
| hsk_declared | 수입신고한 HSK와 처분청이 본 HSK. "신고 4412.31-4019 / 처분청 4412.31-4019"처럼 적는다. 없으면 빈칸 |
| claimant_argument | 청구인(원고) 주장의 핵심 논리. 200자 안팎 |
| agency_argument | 처분청(피고) 주장의 핵심 논리. 200자 안팎 |
| outcome_raw | 주문 그대로 줄여서 |
| outcome | 인용 / 일부인용 / 기각 / 각하 / 재조사. 적부심사의 채택은 인용, 불채택은 기각으로 본다. 판결의 국가패는 인용, 국가승은 기각, 국가일부승소는 일부인용으로 본다 |
| taxpayer_win | Y(인용·일부인용·재조사) / N |
| reasoning_summary | 판단 이유의 핵심 논거. 300자 안팎 |
| scope_criteria_used | 조사범위 사건에서 부과대상 여부를 가른 기준의 유형. data/coding/codebook.md의 유형(규격, 가공상태, 용도, 분류, 제품지정)을 세미콜론으로. 조사범위 사건이 아니면 빈칸 |
| ktc_reference | 무역위원회의 조사·판정·재심사 범위를 근거로 든 대목이 있으면 짧게 인용한다. 없으면 빈칸 |
| related_cases | 결정문에 나오는 다른 사건번호(전심, 병합, 관련 판결, 참조 결정) |
| confidence | 높음 / 중간 / 낮음 |
| note | 판단이 애매한 이유 등 |

## 2. issue_group 정의

- 조사범위: 수입 물품이 부령의 부과대상 물품 또는 제외 물품에 해당하는지가 주쟁점이다.
- 조사범위 부수: 주쟁점은 다른 데 있지만 부과대상 여부도 다투었다.
- 공급자·세율: 물품이 부과대상임을 전제로 어느 공급자의 세율을 적용할지 다툰다. 생산자 확인, 특수관계, 그 밖의 공급자 세율이 여기에 든다.
- 가격약속·과세가격: 가격약속 이행, 최저수출가격, 과세가격 산정을 다툰다.
- 불복 적격: 부령 제정이나 신고납부가 불복 대상 처분이 아니라는 등 청구 요건을 다툰다.
- 기타: 가산세, 감면, 시행시점 등.
- 무관: relevance가 무관이거나 언급이면 무관으로 둔다.

## 3. 원용된 행정기관 회신 (citations 파일)

결정문이 인용한 행정기관의 회신·공문·의결서·질의응답마다 한 행을 둔다. 계획서의 dispute_citation 표다.

| 열 | 값 |
|---|---|
| dispute_id | |
| issuing_agency | 기획재정부 / 재정경제부 / 산업통상자원부 / 무역위원회 / 관세청 / 세관 / 관세평가분류원 / 기타(이름) |
| document | 문서 번호가 있으면 그대로(예: 관세제도과-601). 없으면 빈칸 |
| reply_date | YYYY-MM-DD 또는 YYYY-MM 또는 YYYY |
| cited_by | 청구인 / 처분청 / 심판기관 / 여럿 |
| reply_position | 부과대상 포함 / 부과대상 제외 / 기타 |
| adopted | 심판기관이 그 회신을 따랐으면 Y, 배척했으면 N, 판단하지 않았으면 불명 |
| summary | 회신 취지 100자 안팎 |

회신이 없으면 그 결정의 행은 두지 않는다.

## 4. 초벌 추출 뒤 정한 규칙 (2026-09-27)

여덟 묶음의 추출을 합친 뒤 더한 칸과 판단 규칙이다.

결정 단위 파일에 두 칸을 더한다.

| 열 | 값 |
|---|---|
| decision_group | 같은 결정문을 여러 사건번호로 실은 것(본문이 사실상 같고 결정일이 같은 것)에 같은 값을 준다. 대표 dispute_id를 쓴다. 혼자면 자기 dispute_id |
| dispute_chain | 같은 수입 거래를 두고 과세전적부심사, 심사·심판청구, 판결로 이어진 결정들에 같은 값을 준다. 가장 이른 결정의 dispute_id를 쓴다. 청구인, 물품, 수입기간, 처분 경위가 맞아야 잇는다. 혼자면 자기 dispute_id |

회신 파일에 두 칸을 더한다.

| 열 | 값 |
|---|---|
| scope_related | 회신이 물품이 덤핑방지관세 부과대상인지(조사범위)를 다루면 Y, 품목분류·과세가격·원산지 등 다른 문제면 N |
| reply_key | 같은 회신이 여러 결정에 인용되면 같은 값. "기관-날짜-문서번호" 꼴로 적되, 결정마다 기관명이나 날짜가 하루 이틀 다르게 적혔으면 문서 번호와 취지로 같은 회신인지 판단해 하나로 맞춘다 |

issue_group은 청구인이 무엇을 주장했는지가 아니라 결정기관이 무엇을 판단했는지로 정한다. 원산지를 속여 덤핑방지관세를 피한 사건은 물품의 범위가 아니라 공급국이 쟁점이므로 공급자·세율로 둔다. 본안 판단 없이 각하되었으면 불복 적격이다.

scope_criteria_used는 세미콜론만으로 잇고 공백을 두지 않는다.
