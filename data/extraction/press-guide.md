# 무역위원회 보도자료 항목 추출 지침 (초벌, 2026-09-27)

4단계에서 무역위원회 사건에 신청인과 판정 결과를 채우려고 보도자료에서 뽑는 항목이다. 보도자료 하나가 여러 사건을 다루면 사건마다 한 행을 둔다. 반덤핑 사건(원심, 재심사, 가격약속, 우회덤핑)이 아닌 내용(세이프가드, 불공정무역행위, 행사, 통계)은 행을 만들지 않는다.

| 열 | 값 |
|---|---|
| bbs_id | 입력 그대로 |
| press_date | 입력의 등록일 |
| product | 보도자료가 쓴 물품명 그대로 |
| countries | 대상국. 쉼표로 잇는다. 무역위원회 표기(타이 등) 그대로 |
| case_type | 원심 / 종료재심사 / 중간재심사 / 우회덤핑 / 가격약속 / 불명 |
| stage | 조사개시 / 예비판정 / 최종판정 / 재심사 판정 / 가격약속 수락 / 기타 |
| stage_date | 보도자료가 적은 그 단계의 날짜(위원회 의결일 등). 없으면 빈칸. YYYY-MM-DD |
| determination | 긍정 / 부정 / 일부 긍정 / 해당 없음(개시 등) |
| petitioners | 조사를 신청한 국내 기업·단체 이름. 쉼표로 잇는다. 보도자료에 없으면 빈칸 |
| dumping_margin | 판정된 덤핑률(범위 그대로, 예: 3.98~27.21%) |
| proposed_duty | 기획재정부 장관에게 건의한 덤핑방지관세율 또는 잠정관세율(범위 그대로). 가격약속이면 그 사실 |
| duty_period | 건의한 부과 기간(예: 5년, 4개월) |
| price_undertaking | Y(가격약속 수락·건의) / N / 불명 |
| scope_note | 조사대상물품의 범위나 제외 물품에 대한 서술이 있으면 짧게 인용(100자 안팎) |
| note | 애매한 점 |

값은 보도자료에 적힌 것만 쓴다. 추정하지 않는다.
